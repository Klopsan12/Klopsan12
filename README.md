### 📂 System Portfolio (Active Repositories)

#### 🎵 [Media Stream Engine: TocadoMp3](https://github.com/Klopsan12/TocadoMp3)
Um reprodutor de mídia robusto focado em experiência do usuário e manipulação de fluxos de áudio.
- **Destaques Técnicos:** Implementação de lógica de controle de fila (avançar/retroceder), tratamento dinâmico de metadados (capa e artista) e gerenciamento de estado da interface em tempo real com JavaScript Vanilla.
- **Arquitetura:** Orientada a eventos para garantir baixa latência na interação com os controles de mídia.

#### 🏦 [Evolutionary Transactional Logic: Sistema Bancário](https://github.com/Klopsan12/SistemaBancarioV3)
Este projeto ilustra meu processo de **Refatoração e Iteração**.
- **Versão Atual (V3):** Foco em validações rigorosas e persistência em memória.
- **Legacy Versions:** [V1 - Protótipo Inicial](https://github.com/Klopsan12/Projeto-de-um-Sistema-Banc-rio) | [V2 - Melhoria de Fluxo](https://github.com/Klopsan12/Bancariov2)
- **Insight de Performance:** O sistema evoluiu de scripts lineares para uma estrutura modular, com planejamento para migração de *Listas* para *Hash Maps* para otimização de busca $O(1)$.
